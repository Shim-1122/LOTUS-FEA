Verification vs validation

Verification (equations solved correctly)

LOTUS-FEA runs 47 benchmark checks (rlfea verify) against analytical or independent references: hyperelastic stresses, Coulomb sliding, hinges, cable force balance, restart, near-incompressible locking. Each FEA run checks equilibrium (force imbalance) and element inversion. This page's arithmetic is a set of closed-form estimates listed above; it is not an FEA solve.

Validation (model represents a real limb)

None done. Tissue properties are literature fits from other subjects, the limb is CAD from MRI-based approximations, friction is a screening value, contact is penalty-based, and the gait loads are textbook estimates. No socket has been tested on a patient or bench rig against these numbers.
